# 六足机器人步态模拟与舵机孪生

机器人有六条径向双关节腿。每条腿的大腿长 6.5 cm，小腿长 12.5 cm，足端在本腿的竖直平面内移动。网页采用 +X 为机头、+Y 向上、−Z 为左侧。

## 运行与回放

- 离线回放时，可直接打开 [index.html](index.html)。three.js 已随仓库提供。
- 需要 Web Serial 时，用 Chrome 或 Edge 打开本地站点。在仓库根目录运行 `start-control.bat`，或在本目录运行 `python -m http.server 8000`。连接前关闭占用串口的监视器。
- 选择 **悬空 → 命令回放与足端诊断**，打开 [旧三角首拍日志](samples/legacy.txt) 或 [新三足步态日志](samples/three.txt)。可以播放、拖动时间轴、选择侧视腿号，或切换固定机身接地预览。橙色是目标足端，绿色是根据最终命令反算的位置，灰色是基准站姿。
- 烧录仓库默认的 `MODE_MASTER_CONTROL` 后，悬空面板连接串口会请求完整快照。可以下载当前会话的命令帧。接地预览按同一份日志显示计划支撑及其静态裕量，采用模型机心与髋半径，触地仍需实物测量。
- **触地**模式可单独演示原网页的三角、波纹、对腿规划器。Rapier 使用 60 Hz 固定物理步进和简化触地力。页面在引擎加载失败时显示「理想方向预览」。

## 真机控制

首次烧录后先架空，逐路确认机头、腿号、关节方向和机械间隙。日常启动仍按默认选腿进入站姿。舵机 V+ 使用与舵机匹配的独立供电并与 ESP32 共地。I²C 逻辑电平按 PCA9685 模块的上拉方式匹配。

| 操作 | 命令 | 行为 |
|---|---|---|
| 步态预设 | `gait five` / `gait four` / `gait three` / `gait legacy` | 五足支撑、四足支撑、改良三足支撑、旧三角对照。默认 `three` |
| 方向 | `f fl bl b br fr`、`dir 30`、`mirror` | 六个快捷方向、连续平移方向、镜像腿序。旧三角以 60° 为一档 |
| 执行拍数 | `step`、`walk 3`、`walk cycle`、`stop` | 一拍、指定拍数、一周期、当前一拍落足后逐腿收步 |
| 调参 | `stride 3`、`lift 3`、`height 10`、`dur 600`、`duty 0` | 步幅、抬脚高度、站高、每拍时长、支撑占空比。长度单位为 cm，时长单位为 ms，占空比为 0 时采用预设 |
| 选腿动作 | `legs 0 1`、`cycle`、`one`、`each`、`goto -8 -10`、`home` | 保留选腿、循环、巡检、点动和回位 |
| 舵机直控 | `sv 0 0 67.4`、`ch 1 112.6`、`lsv`、`asv`、`center` | 输入使用逻辑角，输出栏显示最终角及限幅。退出直控时从最后下发的命令复算起点 |
| 查询 | `help`、`state`、`map`、`pos`、`phase`、`verify` | 查看能力、状态、通道与相位 |

真机遥控面板用摇杆发送 `drive [度]`，每 250 ms 续期。松手、失焦或切换页面时发 `stop`；串口中断后，固件在 750 ms 有效期结束时请求收步。串口手动发 `walk` 可连续执行，用 `stop` 收步。旧版固件支持六档方向及网页发出的停止命令。

新步态用单一 20 ms 时钟。换向及换步态在当前拍落足后预摆，有限拍数从实际执行到轨迹终点时累计。规划器按采样检查几何分支和逐路角度限位，可降低抬脚高度、统一缩小各腿的径向步幅或延长每拍时长。`state` 报告采用的参数。旧三角保留原相位及其限幅行为，作为回放和对照使用。

## 校准与串口数据

校准源是 [RobotModel.h](../include/RobotModel.h)。大腿逻辑角为 IK 的外倾角，小腿逻辑角为 180° 减去膝内角。最终角为逻辑角加本路零位偏移后限幅至 0–180°。命令回放先减该偏移，再用正运动学计算髋、膝、足端。PWM 每计数约 0.439°，遥测角保留一位小数。舵机位置、速度和着地由模型估算或实物测量。

| 腿号 | 通道（大腿/小腿） | 偏移 ° | 基准输出 ° |
|---|---|---|---|
| 0 | 0 / 1 | 16 / 50 | 83.38 / 162.62 |
| 1 | 2 / 3 | 0 / 28 | 67.38 / 140.62 |
| 2 | 4 / 5 | 0 / 50 | 67.38 / 162.62 |
| 3 | 6 / 7 | 16 / 50 | 83.38 / 162.62 |
| 4 | 8 / 9 | 0 / 45 | 67.38 / 157.62 |
| 5 | 10 / 11 | 16 / 50 | 83.38 / 162.62 |

`snapshot` 启用 `@FRAME`。每行依次为校准版本、序号、固件时间戳（ms）、阶段、已发拍数、已落足拍数、计划支撑位图、腿序镜像符号，然后为 PCA9685 的 16 个通道槽和六腿目标足端。`-` 表示待同步或空槽。通道槽含逻辑角、最终角和限幅标志。旧 `@SERVO:<ch>:<最终角>` 仍可在网页中解析，回放采用本仓库的校准版本。旧 `MODE_SERVO_TEST` 直接写 PCA9685，适合单独校验输出通道。

## 运动学模型

与固件 `LegKinematics.cpp` 同构（余弦定理，单位 cm）。蜘蛛式折腿：机体小、腿长，髋关节在机身边缘（略低于机心 `hipDrop`）；
大腿从髋向外上拱、小腿从膝盖向下折回着地，膝盖是最高/最外点，侧看呈 "Λ" 拱；髋半径 > 机体半径，腿部几何完全在机体之外（不穿模）。
可达环：内圆 |L1−L2| = 6cm ≤ d ≤ 外圆 L1+L2 = 19cm（d = 髋到足端距离）。

```
d      = √(a² + drop²)                          # a = 足端距髋的径向偏移, drop = 髋到足端落差
膝角 β  = acos((L1² + L2² − d²) / (2·L1·L2))     # π = 直腿, 0 = 完全折回
γ      = acos((L1² + d² − L2²) / (2·L1·d))
髋角 α  = atan2(−drop, a) + γ                    # 相对"水平径向向外"轴, 向上为正
足端    = L1·(cosα, sinα) + L2·(cos(α+π+β), sin(α+π+β))
```

默认站姿同固件 `SingleLeg::defaultStandingFoot`：足端在髋外侧 6.0cm、下方 10.0cm（小腿竖直，脚在膝正下方）；
伸出足到髋外 12.77cm（`extendedFoot` 2/3 分点）→ 本页足端径向范围 `R_LO = hipRadius+6.0` 至 `R_HI ≈ hipRadius+12.8`，
默认机身高度 ≈11.0cm。膝高由 IK 随"机身高度""抬腿高度"实时算出，并非常量。
站姿代进上面的式子：d ≈ 11.66 → 本页 α ≈ +22.62°（Λ 拱）；固件同一姿态是 ag1 = ag2 = +67.38°，对应关系见下节。

## 验证

可在仓库根目录运行以下检查。

```text
pio run -e esp32
python test/check_motion.py
node gait-sim/js/test-gait.js
node gait-sim/js/test-joystick.js
node gait-sim/js/test-mode-switch.js
```

更新校准时递增模型版本，再执行 `python test/check_motion.py --generate` 生成网页配置和回归日志。回归覆盖十二路站姿、首拍 ch7 旧轨迹限幅、三种步态两种腿序下每隔 30° 的全周期、换向换步态、有限拍与收步，以及 30/60/120 Hz 回放。机身尺寸、重心、机械限位、足底滑移、供电和落地速度仍需实物测量。
