# 六足机器人步态模拟器（径向 2 舵机腿 · 蜘蛛式 · 摩擦动力学）

可视化模拟"6 条腿沿正六边形辐条径向安装、每条腿仅 2 个舵机（大腿抬落 + 小腿伸缩）、无转向关节"的构型，
支持 3 种可行步态、任意行进方向、自由视角与参数调节。尺寸取自真实硬件（大腿 8.0cm、小腿 13.0cm，
与 `include/Config.h` 的 LENA/LENB 一致）。
机身不再匀速位移——按真实**库仑摩擦**模型（足底粘住/打滑）在惯性下加速减速。

## 运行方式

**方式一（推荐，离线可用）**：双击打开 `index.html` 即可（three.js 已内置在 `lib/`）。

**方式二（本地服务器）**：
```
python -m http.server 8000        # 在 gait-sim 目录下
```
然后浏览器访问 `http://localhost:8000`。

> 若 `lib/` 缺失或损坏，页面会自动回退到 jsdelivr CDN（需联网）。

## 操作说明

| 操作 | 效果 |
|---|---|
| 鼠标拖拽 | 旋转视角（OrbitControls） |
| 滚轮 | 缩放 |
| 左/右方向键 | 目标方向 φ ±5° |
| 上/下方向键 | 速度 ± |

- **步态模式**：三角步态（3 腿交替支撑，最快）/ 波纹步态（一次只动一条腿，最稳）/ 对腿步态（沿对轴平移，唯一"干净"模式）
- **方向 φ**：目标行进方向（0°=前）。机头（红色箭头）**永远朝 0°**——本构型无法偏航，"转向"= 全向平移（斜走）
- **摩擦 μ**：足底静摩擦系数（动摩擦 = 0.85μ）。μ 越小地面越滑，足底打滑、机身越走越慢——拖动即可直观看到"按摩擦力位移"
- **显示**：足端轨迹 / 机身轨迹 / 支撑腿推力矢量（绿箭头，长短 = 实际推力大小；**红箭头 = 足底滑移**）/ 方位参考环
- 左下方 HUD 实时显示每腿：行程系数 cᵢ、状态（支撑/摆动/悬停，支撑中出现**红字"滑移"**）、足端径向距离、髋角、膝角，以及机身实时速度

## 运动学模型

与固件 `LegKinematics.cpp` 同构（余弦定理，单位 cm）。**蜘蛛式折腿**：机体小、腿长（大腿 8.0cm + 小腿 13.0cm），
髋关节位于机身边缘（略低于机心，`hipDrop`），大腿从髋向外上拱，小腿从膝盖向下折回着地，膝盖是最高/最外点，
侧看呈 "Λ" 拱。髋关节半径 > 机体半径，腿部几何完全位于机体之外——**不穿模**。
可达环：内圆 |L1−L2| = 5cm ≤ d ≤ 外圆 L1+L2 = 21cm（d = 髋到足端距离）。

默认站立足与固件 `SingleLeg::defaultStandingFoot` 一致：足端在髋外侧 5.0cm、下方 6.755cm
（小腿竖直，脚在膝正下方，膝盖离地 13cm）；伸出足到髋外侧 14.9cm（固件 `extendedFoot` 2/3 分点）。
对应模拟器足端径向范围 `R_LO = hipRadius+5.0` 至 `R_HI ≈ hipRadius+14.9`，默认机身高度 ≈ 7.8cm
（足端始终着地，膝盖在整个步态包络内离地 ≥ 9cm，不会"用膝盖走路"）。

```
d    = √(a² + drop²)              # a=足端距髋的径向偏移, drop=髋到地高度 (髋低于机心 hipDrop)
膝角 β = acos((L1² + L2² − d²) / (2·L1·L2))   # π=直腿, 0=完全折回
γ    = acos((L1² + d² − L2²) / (2·L1·d))
髋角 α = atan2(−drop, a) + γ                  # 相对"水平径向向外"轴, 向上为正
足端 = L1·(cosα, sinα) + L2·(cos(α+π+β), sin(α+π+β))
```

固件对照：固件 `LegKinematics::ik` 返回的 `thigh`(ag2，从竖直轴向外为正) = 90° − α，`knee`(ag1) = β。

步态核心规则（行程系数投影法）：

```
cᵢ = cos(φ − αᵢ)      # φ=目标方向, αᵢ=腿方位角
cᵢ > 0 → 支撑相"收"(拉地)    cᵢ < 0 → 支撑相"伸"(蹬地)
支撑相: 前腿收、后腿伸；摆动相相反
足端扫掠采用轻度 S 曲线 (起止不归零、中段最快) → 驱动速度随相位变化
```

## 动力学模型（摩擦 · 粘滑）

机身不再匀速。每条支撑腿相当于一个**弹簧-阻尼驱动**的足端：

```
F_i = k·(r − r_cmd) + c·(ṙ − ṙ_cmd)      # 期望推力 (沿径向, 正=向外; r_cmd 由规划器给出, ṙ_cmd 解析求得)
```

- 足端落地即"钉"在地面（世界位置固定）；机身速度 v 使实际径向坐标按 ṙ = −v·ê 变化。
- 推力被**库仑摩擦**封顶：|F_i| ≤ μ_s·N（N = mg/支撑腿数）。未超限 → 足底粘住，力全量传给机身；
  超限 → 足底沿径向**滑移**，动摩擦 μ_k·N 抵抗足端相对地面的速度（正则化平滑 + 迟滞再粘住，避免高频抖动）。
- 机身按 F = m·a 积分（外加平动阻力），从而真实地**加速、减速、打滑**；物理积分采用 8ms 亚步进保证稳定。
- ≥3 腿同时支撑时的运动学锁死由足底微滑移自然化解（HUD 红字"滑移"、红箭头、足端轨迹可见滑动）。
- **摩擦 μ 的影响**（三角步态、默认速度实测）：μ=1.0 完全抓地；μ≈0.15 起偶发滑移；
  μ=0.1 足底大面积打滑、速度约减半；μ=0.05 近似"冰面"，匍匐前进。
- 三腿一组时合力方向仍指向目标 φ（几何性质，与旧净推力模型一致），但大小随相位波动 → 机身速度在每一步中起伏。

## 已知简化（与真实物理的差异）

1. **简化摩擦模型**：采用理想库仑摩擦（静摩擦 μ_s·N / 动摩擦 0.85·μ_s·N），无粘弹性地面、无足底-地面冲击反弹。
2. **无舵机角度限位**：髋/膝角只做余弦夹逼，超出机械限位时足端会"够不到"（可看到腿伸直但仍触不到地）。
3. **机身高度恒定**：真实行走中机身会随步态轻微起伏（本模拟保持恒定，足底压力均分给所有支撑腿）。
4. **摆动腿不参与动力学**：摆动/悬停腿视为无接触，忽略其质量转移与空气阻力（机身平动阻力为简化常数）。

## 文件结构

```
gait-sim/
├─ index.html          入口（含库加载与 CDN 回退）
├─ style.css           界面样式
├─ js/
│  ├─ robot.js         三维模型 + 逆运动学（蜘蛛式构型, 尺寸与 Config.h 一致）
│  ├─ gaits.js         步态规划器（三角/波纹/对腿, S 曲线扫掠）
│  ├─ main.js          场景、相机、UI、摩擦动力学主循环
│  └─ test-gait.js     单元测试（node js/test-gait.js 运行）
└─ lib/                three.js r147 本地库（离线可用）
```

## 自定义

- 改尺寸：`js/robot.js` 的 `CONFIG`（大腿/小腿长、机体半径、足端径向范围），并同步改 `include/Config.h` 的 `LENA/LENB`
- 改步态时序：`js/gaits.js`（摆动窗、支撑比例、速度增益）
- 更多腿 / 其他方位角：改 `CONFIG.azimuths` 即可
