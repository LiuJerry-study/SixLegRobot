# 六足机器人 · 步态模拟 / 舵机孪生（径向 2 舵机腿 · 蜘蛛式）

可视化"6 条腿沿正六边形辐条径向安装、每条腿 2 个舵机（大腿抬落 + 小腿伸缩）、无转向关节"的构型。
尺寸取自真实硬件：大腿 6.5cm、小腿 12.5cm（与 `include/Config.h` 的 LENA/LENB 一致）。
页面顶部切两大模式，两者互斥（串口独占，切模式时自动断开另一面板）：

| 模式 | 面板 | 做什么 |
|---|---|---|
| 🪝 悬空 · 舵机孪生 | `js/twin-panel.js` | 机器人吊在架上；网页经 Web Serial 独占串口发命令控制真机，并把固件回传的 12 路 `@SERVO` 遥测 1:1 镜像到 3D |
| 🐾 触地 · 步态模拟 | `js/control-panel.js` | 站在地面跑三角/波纹/对腿步态 + 摩擦动力学；勾选"目标点遥控"后点地面 = 全体足端 goto |

## 运行

- **双击 `index.html`**（推荐，离线可用）：three.js 已内置在 `lib/`；物理引擎 Rapier 走 CDN，离线时自动降级为**无物理模式**并在页面提示。
- **本地服务器**：`python -m http.server 8000`（本目录）→ `http://localhost:8000`；仓库根目录 `start-control.bat` 可一键启动。
- **串口功能**（两种模式都要）：必须 **Chrome / Edge** + `http://localhost` 打开；连接前关闭 PlatformIO / Arduino 串口监视器（串口独占）。

## 悬空 · 舵机孪生

1. 烧任一**经 `ServoManager::write()` 写舵机**的固件即可（单舵机 / 单腿 / 六腿同步…都行）；换模式只改 `platformio.ini` 的 `-DMODE_XXX` 再 Upload。
2. 打开页面 → 点"🪝 悬空模式" → 面板里选/自动识别固件模式 → "🔌 连接串口"。
3. 在命令框发命令（或点快捷键）控制真机。固件每次真正驱动某路舵机都回传 `@SERVO:<ch>:<角度>`：
   ch = leg×2 + joint = `SERVO_PINS[leg][joint]`（0=大腿 1=小腿）；角度 = 逻辑角 + `ANGLE_OFFSET` 再限幅 0~180 的最终角
   （`Config.h::ANGLE_OFFSET` **整表已清零** → 当前最终角 = 逻辑角）；
   节流条件 = 变化 ≥0.5° 且每通道 ≥50ms。网页解析后 12 路舵机同步转动，通道表实时显示角度。
4. 没有硬件时勾选 **离线扫动演示**，预览 ch0~ch11 的镜像方向。
5. 镜像约定：`robot.js::applyServoAngles()` 直接按最终角摆姿态 —— 大腿 α = 90°−S、小腿 knee = −K。
   真机某腿舵机装反时改固件（`SingleLeg.cpp` 的 `thighDeg` 或 `Config.h` 的 `ANGLE_OFFSET`），孪生侧不用改。
   ⚠ 该映射与固件口径自洽：S = ag2 → α = 90°−ag2，K = 180 − ag1 → knee = ag1 − 180（见下「固件 ↔ 仿真角度口径」）。
6. 默认姿态双 90° 只是**未收到遥测时的显示占位**、**不是站姿**（站姿 = 大腿 67.4° / 小腿 112.6°）；
   固件 `center` 同样把 12 路发到 90°（`ANGLE_OFFSET` 已清零 → 回传即 90°），那只是安全位。

## 触地 · 真机遥控

1. `platformio.ini` 换成 `-DMODE_SIX_LEGS_SYNC` 后 Upload（当前生效的是 `-DMODE_SINGLE_LEG_TEST`）。
2. 勾选"🎯 目标点遥控"（视角拖拽暂停，左键让给点选）→ 点击/拖拽地面：只取目标点到机心的**径向距离 r**
   （限幅 `[R_LO, R_HI]`），6 条腿足端同步落到半径 r 的目标环上，同时发 `goto <x> <y>`
   （x = −(r − hipRadius)、y = −drop，drop = 机心高 − hipDrop ≈ 10.0cm）。
3. 其余按钮：站立(home) / 循环行走(cycle) / 停止(stop) / 读状态(pos)、动作时长滑块、手动命令框。

## 操作说明

| 操作 | 效果 |
|---|---|
| 鼠标拖拽 / 滚轮 | 旋转视角 / 缩放 |
| 左 / 右方向键 | 目标方向 φ ±5° |
| 上 / 下方向键 | 速度 ± |

- **步态模式**：三角（3 腿交替支撑，最快）/ 波纹（一次只动一条腿，最稳）/ 对腿（沿对轴平移，唯一"干净"模式）
- **方向 φ**：目标行进方向（0°=前）。机头（红色箭头）永远朝 0°——本构型无法偏航，"转向"＝全向平移（斜走）
- **摩擦 μ**：足底静摩擦系数（动摩擦 = 0.85μ）；μ 越小地面越滑，足底打滑、机身越走越慢
- **显示**：足端轨迹 / 机身轨迹 / 支撑腿推力矢量（绿=实际推力，红=足底滑移）/ 方位参考环
- 左下 HUD：每腿行程系数 cᵢ、状态（支撑/摆动/悬停，滑移时红字）、足端径向距离、髋角、膝角，以及机身实时速度

## 运动学模型

与固件 `LegKinematics.cpp` 同构（余弦定理，单位 cm）。蜘蛛式折腿：机体小、腿长，髋关节在机身边缘（略低于机心 `hipDrop`）；
大腿从髋向外上拱、小腿从膝盖向下折回着地，膝盖是最高/最外点，侧看呈 "Λ" 拱；髋半径 > 机体半径，腿部几何完全在机体之外（不穿模）。
可达环：内圆 |L1−L2| = 6cm ≤ d ≤ 外圆 L1+L2 = 19cm（d = 髋到足端距离）。

```
d      = √(a² + drop²)                          # a = 足端距髋的径向偏移, drop = 髋到足端落差
膝角 β  = acos((L1² + L2² − d²) / (2·L1·L2))     # π = 直腿, 0 = 完全折回
γ      = acos((L1² + d² − L2²) / (2·L1·d))
髋角 α  = atan2(−drop, a) + γ                    # 相对"水平径向向外"轴, 向上为正
足端    = L1·(cosα, sinα) + L2·(cos(α+π+β), sin(α+π+β))
```

默认站姿同固件 `SingleLeg::defaultStandingFoot`：足端在髋外侧 6.0cm、下方 10.0cm（小腿竖直，脚在膝正下方）；
伸出足到髋外 12.77cm（`extendedFoot` 2/3 分点）→ 本页足端径向范围 `R_LO = hipRadius+6.0` 至 `R_HI ≈ hipRadius+12.8`，
默认机身高度 ≈11.0cm。膝高由 IK 随"机身高度""抬腿高度"实时算出，并非常量。
站姿代进上面的式子：d ≈ 11.66 → 本页 α ≈ +22.62°（Λ 拱）；固件同一姿态是 ag1 = ag2 = +67.38°，对应关系见下节。

步态核心规则（行程系数投影法）：

```
cᵢ = cos(φ − αᵢ)      # φ = 目标方向, αᵢ = 腿方位角
cᵢ > 0 → 支撑相"收"(拉地)    cᵢ < 0 → 支撑相"伸"(蹬地); 摆动相相反
足端扫掠用轻度 S 曲线（起止不归零、中段最快）→ 驱动速度随相位变化
```

## 固件 ↔ 仿真角度口径

固件 `LegKinematics::ik()` 返回的**是弧度**（`src/SingleLeg.cpp::writeServosFromRad()` 里乘一次 180/π 转成度，全链路只换算这一次）：

```
knee  = acos((LENA² + LENB² − d²) / (2·LENA·LENB))                     # 两连杆夹角 ag1: 180° = 完全伸直、0° = 完全折叠, 恒为正
                                                                        # （弯曲角 θ = 180° − ag1；站姿 67.38° → θ = 112.62°）
thigh = −( acos((LENA² + d² − LENB²) / (2·LENA·d)) + atan2(fx, fy) )   # 机腿角 ag2: 外倾为正
```

- 默认站姿足 (−6, −10)：d ≈ 11.66 → **ag1 ≈ +67.38°、ag2 ≈ +67.38°**（2026-09-10 起"外倾为正"，不再有负号）。
- 舵机映射（2026-09-10 实物实测改版）：**大腿舵机角 S = ag2**（站姿 67.38°）、**小腿舵机角 K = 180 − ag1**（站姿 112.62°）。
  实测口径：大腿舵机 0° = 大腿竖直向上、180° = 竖直向下，中间经过"机体外侧"那半边 → 舵机角直接就是 ag2。
  ⚠ 旧的大腿映射（在 ag2 上多加 90° 偏置、把"竖直向上"当成 0°）**已作废**，那是按错口径标定的结果。
- `Config.h::ANGLE_OFFSET` **整表已清零**（旧值按错映射标定，作废待重标定）→ **最终写入角 = 逻辑角**。
  行程口径：大腿 0~180° ↔ ag2 ∈ [0°, 180°]，可用外拱区间 ag2 ∈ [0°, 90°]；ag2 < 0（脚抬到髋高以上）
  会被限幅到 0°（大腿竖直向上）。小腿 `180 − ag1` 与其行程口径都不变。
- 与 3D 仿真：本页 α（相对"水平径向向外"轴、向上为正）= **90° − ag2**（旧的负号口径已作废），
  站姿 α = 90 − 67.38 = +22.62°，仍是 Λ 拱。
- 孪生侧**反向映射**：`@SERVO` 回传的 (S, K) → α = **90°−S**、`knee.rotation.z` = −K
  （因为 S = ag2、K = 180 − ag1），与固件口径一致，**不需要补偿**。
  注意 S/K 是**叠加零位偏移后**的最终角；偏移已清零，所以它就是逻辑角本身，孪生按它 1:1 摆姿态、不反向换算。

## 动力学模型（摩擦 · 粘滑）

机身不匀速：每条支撑腿是一个**弹簧-阻尼驱动**的足端，推力被库仑摩擦封顶，机身按 F = ma 积分（Rapier 固定 60Hz 步进）。

```
F_i = k·(r − r_cmd) + c·(ṙ − ṙ_cmd)   # 期望推力(沿径向), r_cmd 由规划器给出, ṙ_cmd 为解析解
|F_i| ≤ μ_s·N                          # 未超限: 足底粘住, 力全量传给机身
                                       # 超限: 足底沿径向滑移, 动摩擦 μ_k·N 抵抗相对速度(正则化 + 迟滞再粘)
```

- 足端落地即"钉"在地面（世界位置固定），机身速度使实际径向坐标按 ṙ = −v·ê 变化。
- 机身高度由支撑腿**虚拟弹簧-阻尼**悬浮（均分重量 + 高度控制）；姿态由水平稳定器保持（机身水平、机头恒朝 0°）。
- ≥3 腿同时支撑时的运动学锁死由足底微滑移自然化解（HUD 红字"滑移"、红箭头、足端轨迹可见滑动）。
- μ 实测（三角步态、默认速度）：μ=1.0 完全抓地；μ≈0.15 起偶发滑移；μ=0.1 大面积打滑、速度约减半；μ=0.05 近似"冰面"。

## 已知简化（与真实物理的差异）

1. **简化摩擦模型**：理想库仑摩擦（静 μ_s·N / 动 0.85μ_s·N），无粘弹性地面、无足底-地面冲击反弹。
2. **无舵机角度限位**：髋/膝角只做余弦夹逼，超机械限位时足端会"够不到"（腿伸直但仍触不到地）。
3. **机身高度由弹簧-阻尼悬浮**：真实行走的机身起伏被近似，幅度很小；足底压力均分给所有支撑腿。
4. **摆动腿不参与动力学**：摆动/悬停腿视为无接触，忽略其质量转移；机身平动阻力为简化常数。

## 已知问题（待修）

1. **`MODE_SERVO_TEST` 无遥测**：该模式在 `src/main.cpp` 内联、直写 PCA9685、绕过 `ServoManager::write()`，选它时悬空孪生不会动。
2. **无物理模式没有推力矢量**：Rapier 加载失败时 `foot[i].force` 恒为 0，绿/红箭头不显示（轨迹、HUD 仍可用）。
3. **跟随相机高度写死**：跟随目标用 y=8（旧口径），当前默认站高 11.0，跟随时视线偏低。
4. **法向力口径不一**：单腿法向力按固定 `PHYS_M = 2.0kg` 估算，而垂直支撑/姿态增益用实测 `Physics.getMass()`。
